# ТЗ №11

## Название

Перенос критерия богатой комнаты из terminal.manager.js в empire.js

---

## Цель

Продолжить архитектурную очистку `terminal.manager.js`.

Настоящее ТЗ выполняется строго в рамках ранее принятого решения:

- не искать ошибки;
- не исправлять балансировку;
- не объединять системы;
- не менять бизнес-логику;
- не проводить диагностику;
- только переносить управление из исполнительных модулей в `empire.js`.

Переносится исключительно решение:

> «Является ли комната богатой по энергии?»

Поведение Империи должно остаться полностью неизменным.

---

## Что необходимо сделать

### 1. Добавить метод в empire.js

Создать новый метод:

```js
isEnergyRichRoom(room, storageEnergy) {
  return storageEnergy > this.energy.richThreshold;
},
```

Требования:

- использовать существующий `this.energy.richThreshold`;
- не менять значение порога;
- не менять оператор сравнения;
- не добавлять новые проверки;
- не изменять сигнатуру метода.

---

### 2. Изменить terminal.manager.js

Найти код:

```js
const richRooms = rooms.filter(
  r => (r.storage.store[RESOURCE_ENERGY] || 0) > ENERGY_RICH_THRESHOLD,
);
```

Заменить на:

```js
const richRooms = rooms.filter(r =>
  empire.isEnergyRichRoom(r, r.storage.store[RESOURCE_ENERGY] || 0),
);
```

---

### 3. Ничего больше не менять

Запрещается:

- менять критерий бедной комнаты;
- менять выбор донора;
- менять выбор получателя;
- менять объём отправки;
- менять логику подготовки к продаже;
- менять запуск балансировки;
- менять resourceBalancer;
- исправлять рассогласованности;
- объединять системы балансировки;
- проводить рефакторинг за пределами данного ТЗ.

---

## Что НЕ является целью ТЗ

Не выполнять архитектурное объединение.

Не исправлять противоречия между:

- terminal.manager.js
- resourceBalancer.js

Не изменять существующие пороги.

Не изменять работу Империи.

Не заниматься поиском причин текущих неисправностей балансировки.

---

## Критерии приёмки

### empire.js

Присутствует метод:

```js
isEnergyRichRoom(room, storageEnergy);
```

---

### terminal.manager.js

Отсутствует выражение:

```js
storageEnergy > ENERGY_RICH_THRESHOLD;
```

или его эквивалент.

---

Присутствует вызов:

```js
empire.isEnergyRichRoom(...)
```

---

Логика работы модуля не изменена.
