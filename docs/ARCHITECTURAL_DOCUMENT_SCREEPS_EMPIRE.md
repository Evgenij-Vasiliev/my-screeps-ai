Дорожная карта Империи Screeps
Версия 2.0
Статус: Обсуждение
Главная цель
Построить управляемую технократическую империю.
Главный ограниченный ресурс:
CPU.
Главная угроза:
сложность управления.
Главный принцип:
минимально необходимая сложность.

Фаза 0. Архитектурный фундамент
Цель:
Сделать систему понятной человеку.
Результат:
Любой сбой локализуется за несколько минут.
Основные направления:
единая многокомнатная архитектура;
единая модель комнаты;
единая система ответственности;
удаление мёртвого кода;
отказ от дублирования.
Критерий завершения:
Координатор понимает структуру проекта без изучения всего кода.

Фаза 1. Наблюдаемость
Цель:
Всегда понимать текущее состояние империи.
Результат:
Империя умеет объяснять своё состояние.
Основные направления:
диагностика комнат;
диагностика логистики;
диагностика спавна;
диагностика удалённых операций;
журнал событий.
Критерий завершения:
На любой вопрос "что сломалось?" система отвечает самостоятельно.

Фаза 2. Самовосстановление
Цель:
Система автоматически устраняет типовые проблемы.
Результат:
Большинство аварий не требуют вмешательства игрока.
Основные направления:
восстановление популяции;
восстановление логистики;
контроль критических ролей;
контроль инфраструктуры.
Критерий завершения:
Потеря отдельных крипов не требует ручного вмешательства.

Фаза 3. Управление
Цель:
Обеспечить удобное ручное управление поверх автоматики.
Результат:
Игрок может вмешиваться в работу империи без переписывания логики.
Основные направления:
глобальные команды;
команды комнатам;
команды группам крипов;
команды отдельным крипам;
временные приоритеты.
Критерий завершения:
Любая операция может быть запущена через систему команд.

Фаза 4. Экономическое ядро
Цель:
Стабильная работа всех собственных комнат.
Результат:
Комнаты полностью автономны.
Основные направления:
энергия;
логистика;
Storage;
Terminal;
Link-сеть.
Критерий завершения:
Собственные комнаты не требуют ручного контроля.

Фаза 5. SK-программа
Цель:
Освоение операций повышенной сложности.
Результат:
Стабильная добыча энергии и минералов в SK-комнатах.
Основные направления:
специализированные роли;
специализированные бусты;
маршруты снабжения;
защита операций;
оценка опыта эксплуатации.
Критерий завершения:
SK-добыча работает длительное время без вмешательства игрока.

Фаза 6. Лабораторный комплекс
Цель:
Автоматическое обеспечение всех необходимых бустов.
Результат:
Империя производит бусты по запросу потребителей.
Основные направления:
стандартизация наборов бустов;
производство реагентов;
контроль запасов;
снабжение операций.
Критерий завершения:
Любая утверждённая операция автоматически получает необходимые бусты.

Фаза 7. Рыночная экономика
Цель:
Использовать рынок как инструмент балансировки империи.
Результат:
Излишки автоматически превращаются в полезные ресурсы.
Основные направления:
продажа излишков;
закупка дефицитов;
межкомнатный баланс;
управление резервами.
Критерий завершения:
Проблема переполненных хранилищ устранена.

Фаза 8. Производственный контур
Цель:
Использовать инфраструктуру высокого уровня.
Результат:
Работают Factory и Power Spawn.
Основные направления:
обработка Power;
производство товаров;
управление цепочками ресурсов.
Критерий завершения:
Высокоуровневая инфраструктура участвует в экономике.

Фаза 9. Стратегический контур
Цель:
Подготовка к долгосрочным операциям.
Результат:
Империя способна планировать развитие территории.
Основные направления:
Observer;
разведка;
анализ регионов;
подготовка новых направлений развития.
Критерий завершения:
Расширение территории становится планируемым процессом.

Архитектурные запреты
Запрещается:
создавать новый модуль без явной необходимости;
создавать дублирующие системы;
добавлять сложность без измеримой пользы;
автоматизировать процессы, которые используются редко;
внедрять функциональность без диагностики.
Любое усложнение должно иметь экономическое или управленческое обоснование.
