Вам нужно спроектировать и написать код двух задач для работы воркеров на фабрике. Производством батареек занимается factory.manager - для наших задач только логистика.
Задача 1 - доставить энергию из хранилища в фабрику до тех пор пока в хранилище фабрики есть свободное место и в хранилище комнаты энергии ENERGY_MIN + 10% - лучше создать отдельную константу в constants.
Условия создания задачи - пока есть место в хранилище фабрики(практически всегда)
Условия завершения задачи -

1. задача выполнена
2. задача невыполнима
3. закончилась энергия в рюкзаке(заправился - завез - выгрузился - задача закончена - воркер берет следующую задачу)

Задача 2 - забрать батарейки с фабрики и доставить и в хранилище комнаты
условия создания задачи - наличие батареек в хранилище фабрики
Условия завершения задачи -

1. задача выполнена
2. задача невыполнима
3. нет места в рюкзаке

Обе задачи должны иметь реверсивное действие - работать в обратную сторону - завозить батарейки и забирать энергию
