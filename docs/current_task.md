Вам нужно спроектировать и написать код для блока дальней добычи + блок обороны для аттакеров которые будут защищать комнаты дальнегот сбора.
В блок дальней добычи(ремоте менеджер) будут входить модули - резервер - дальный майнер - дальный хайлер. В блоке обороны пока что только модуль аттакеров. Есть файлы модулей из прошлой итерации империи - можно посмотреть и использовать как образец, но поиск у нас должен быть без файнд.

Нужно взять файлы ролей которые будут у вас в контексте и адаптировать их к условиям теперешней империи.
Вы можете запросить нужные файлы из теперешней империи но с учетом эколномии по лимитам сообщений - и по одному за раз и только для того чтобы встроить старые файлы в новую империю.
