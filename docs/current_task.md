Вам нужно спроектировать и написать код для блока дальней добычи
В блок дальней добычи(ремоте менеджер) будут входить модули - резервер - дальный майнер - дальный хайлер. Есть файлы модулей из прошлой итерации империи - нужно адаптировато эти файлы ролей для работы в теперешней империи.

Вы можете запросить нужные файлы из теперешней империи но с учетом эколномии по лимитам сообщений - и по одному за раз и только для того чтобы встроить старые файлы в новую империю.
