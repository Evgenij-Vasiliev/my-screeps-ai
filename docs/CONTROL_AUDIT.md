# CONTROL AUDIT

## Цель

Построение централизованной и управляемой архитектуры Screeps Empire.

Основной принцип:

CONTROL принимает решения.

Исполнительные модули выполняют решения.

---

- отсутствуют

Вердикт:

---

## resourceBalancer.js

Статус: ЧИСТЫЙ ИСПОЛНИТЕЛЬ

Назначение:

- балансировка ресурсов между комнатами
- выполнение решений Империи

Встроенные решения:

- отсутствуют

Перенесено в empire.js:

- RESERVE_MIN
- DEFICIT_THRESHOLD
- SEND_AMOUNT
- выбор получателя
- выбор донора
- критерий дефицита
- критерий донора
- BALANCE_INTERVAL
- TERMINAL_ENERGY_MIN
- timeout входящих поставок

Вердикт:

- рефакторинг завершён
- дальнейшие архитектурные изменения через empire.js
- допускаются исправления ошибок без изменения архитектуры

# Архитектурные проблемы

## Проблема №1

Экономические правила распределены по исполнительным модулям.

Подтверждено:

- terminal.manager.js
- market.manager.js

Устранено:

- resourceBalancer.js (ТЗ №1–№9)

Следствие:

- разные модули могут принимать противоречащие друг другу решения

ЧАСТИЧНО УСТРАНЕНО
