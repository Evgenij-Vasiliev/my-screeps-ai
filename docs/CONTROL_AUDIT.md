# CONTROL AUDIT

## Цель

Построение централизованной и управляемой архитектуры Screeps Empire.

Основной принцип:

CONTROL принимает решения.

Исполнительные модули выполняют решения.

---

# Просмотренные модули

## main.js

Статус: ЧИСТЫЙ

Назначение:

- точка входа системы
- запуск roomManager для каждой комнаты

Решения:

- отсутствуют

Вердикт:

- соответствует будущей архитектуре

---

## room.manager.js

Статус: КООРДИНАТОР

Назначение:

- запуск подсистем комнаты

Решения:

- практически отсутствуют

Вердикт:

- является контейнером подсистем
- не является центром управления

---

## spawn.manager.js

Статус: ИСПОЛНИТЕЛЬ

Назначение:

- поддержание квот крипов

Решения:

- проверка нехватки роли
- запуск спавна

Особенности:

- квоты задаются вручную игроком

Вердикт:

- не является источником экономической политики
- пока оставить без изменений

---

## terminal.manager.js

Статус: СМЕШАННАЯ ОТВЕТСТВЕННОСТЬ

Назначение:

- энергетическая балансировка
- подготовка ресурсов
- обработка входящих поставок

Встроенные решения:

- определение бедных комнат
- определение богатых комнат
- выбор донора
- выбор получателя

Вердикт:

- содержит элементы экономической политики
- требует разделения в будущем

---

## resourceBalancer.js

Статус: КРИТИЧЕСКИЙ

Назначение:

- балансировка ресурсов между комнатами

Встроенные решения:

- определение дефицита
- определение резерва
- выбор донора
- выбор получателя
- объём поставки

Вердикт:

- один из основных носителей экономической политики
- приоритетный кандидат на рефакторинг

---

## market.manager.js

Статус: ОТКЛЮЧЕН

Назначение:

- продажа ресурсов через чужие buy orders

Встроенные решения:

- что разрешено продавать
- какой запас считается излишком

Наблюдение:

- ранее возникала потеря управляемости
- продажу энергии пришлось отключать комментированием кода

Вердикт:

- содержит собственную экономическую политику

# Архитектурные проблемы

## Проблема №1

Экономические правила распределены по исполнительным модулям.

Подтверждено:

- terminal.manager.js
- resourceBalancer.js
- market.manager.js

Следствие:

- разные модули могут принимать противоречащие друг другу решения

Статус:
ПОДТВЕРЖДЕНО
