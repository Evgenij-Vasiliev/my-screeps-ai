# Правила работы в этом проекте

## Запреты
1. Ни одной правки, выгрузки, спавна, suicide и вообще любого действия
   без явной команды человека. «Стоп» значит «ничего не делать»,
   а не «поменяй формат».
2. Никаких массовых операций над флотом (suicide, переспавн, смена квот). Никогда.
3. Никаких изменений в системе задач без отдельного согласования:
   task.manager.js, task.executors.js, task.generators.js,
   task.types.js, worker.runner.js.

## Утверждения
4. Каждое утверждение — либо файл:строка, либо цифра из замера с командой.
   Нет ссылки — это гипотеза, и её запрещено использовать как основание.
5. Нет данных — говорить «не знаю». Оценка вместо факта запрещена.
6. Поведение бота проверять замером на живом шарде, а не выводить из чтения кода.

## Формат работы
7. Один шаг — одно действие, у каждого шага есть точка отката.
8. Порядок: read-only замер → предложение → согласование → правка →
   тесты → выгрузка. Выгрузка — всегда отдельная команда человека.
9. Перед правкой прогнать тесты: node tests/<файл>.test.js (всего 15 файлов),
   правила CPU механически держит tests/rules.test.js.
10. Перед выгрузкой — node scripts/check.require.cycles.js: циклический
   require движок Screeps (в отличие от Node) не разрешает и роняет загрузку
   всех модулей. Проверка живости после выгрузки:
   node scripts/check.shard.alive.js shard3 — окно по умолчанию 15 с даёт
   ложную тревогу (cpuMonitor пишет cpuStats раз в 10 тиков), брать 60 с.
